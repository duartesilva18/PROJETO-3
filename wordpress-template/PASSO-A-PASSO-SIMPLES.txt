  GUIA SUPER SIMPLES - DO ZIP À PÁGINA FUNCIONANDO
═══════════════════════════════════════════════════════════════

🎯 OBJETIVO: Instalar WordPress e adicionar a página de notícias
📌 NOTA: Esta página usa a tua API NestJS (não precisa de MySQL para notícias)


═══════════════════════════════════════════════════════════════
  PARTE 1: INSTALAR WORDPRESS
═══════════════════════════════════════════════════════════════

PASSO 1: INSTALAR XAMPP
────────────────────────
1. Descarrega: https://www.apachefriends.org/
2. Instala o XAMPP
3. Abre XAMPP Control Panel
4. Clica "Start" em Apache
5. Clica "Start" em MySQL
   → Ambos devem ficar VERDES ✅


PASSO 2: EXTRAIR WORDPRESS
──────────────────────────
1. Extrai o ZIP do WordPress
2. Copia a pasta para: C:\xampp\htdocs\
   Exemplo: C:\xampp\htdocs\wordpress\


PASSO 3: CRIAR BASE DE DADOS
─────────────────────────────
1. Abre: http://localhost/phpmyadmin
2. Clica "Novo" (New)
3. Nome: wordpress_db
4. Collation: utf8_general_ci
5. Clica "Criar"


PASSO 4: INSTALAR WORDPRESS
───────────────────────────
1. Abre: http://localhost/wordpress
2. Escolhe idioma: Português
3. Clica "Vamos começar!"
4. Preenche:
   - Base de dados: wordpress_db
   - Utilizador: root
   - Palavra-passe: (deixa vazio)
   - Servidor: localhost
5. Clica "Submeter"
6. Clica "Executar a instalação"
7. Preenche:
   - Título do site: (o que quiseres)
   - Nome de utilizador: (escolhe um)
   - Palavra-passe: (escolhe uma forte)
   - Email: (o teu email)
8. Clica "Instalar WordPress"
9. ✅ ANOTA o nome de utilizador e palavra-passe!


PASSO 5: ENTRAR NO WORDPRESS
─────────────────────────────
1. Vai a: http://localhost/wordpress/wp-admin
2. Entra com o utilizador e palavra-passe
3. ✅ WordPress instalado!


═══════════════════════════════════════════════════════════════
  PARTE 2: ADICIONAR PÁGINA DE NOTÍCIAS
═══════════════════════════════════════════════════════════════

PASSO 1: VER QUAL É O TEMA
───────────────────────────
1. No WordPress Admin: Aparência → Temas
2. O tema com borda AZUL é o tema ativo
3. Anota o nome (ex: twentytwentyfour)


PASSO 2: COPIAR FICHEIROS
──────────────────────────
1. Abre: C:\xampp\htdocs\wordpress\wp-content\themes\
2. Abre a pasta do tema ativo (ex: twentytwentyfour)
3. Copia para lá:
   ✓ page-lista-noticias.php
   ✓ style-lista-noticias.css


PASSO 3: EDITAR functions.php
─────────────────────────────
1. Na mesma pasta, abre functions.php
2. Copia TODO o código de functions-lista-noticias.php
3. Cola no FINAL do functions.php
4. Guarda


PASSO 4: CRIAR PÁGINA
─────────────────────
1. No WordPress: Páginas → Adicionar Nova
2. Nome: "Lista de Notícias"
3. Lado direito: "Atributos da Página" → "Modelo"
4. Seleciona "Lista de Notícias"
5. Clica "Publicar"


PASSO 5: VER A PÁGINA!
──────────────────────
Clica "Ver página" → ✅ DEVE FUNCIONAR!


═══════════════════════════════════════════════════════════════
  PROBLEMAS?
═══════════════════════════════════════════════════════════════

❌ Não abre localhost?
   → Verifica se Apache está VERDE no XAMPP

❌ Erro na base de dados?
   → Verifica se MySQL está VERDE no XAMPP

❌ Não vejo o template?
   → Verifica se os ficheiros estão na pasta correta

❌ Página em branco?
   → Verifica se o código no functions.php está correto
